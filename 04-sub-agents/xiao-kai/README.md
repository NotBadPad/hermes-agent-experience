## ⚠️ 注意事项

1. **Token 消耗**：代码任务 token 消耗较大，注意控制单次任务范围
2. **沙箱执行**：终端命令具备真实执行能力，避免在生产环境执行未经确认的命令
3. **上下文管理**：大型项目建议拆分多个会话，避免超出上下文窗口
4. **模型限制**：超长代码理解和生成任务建议分步进行，避免一次性塞入过大上下文
